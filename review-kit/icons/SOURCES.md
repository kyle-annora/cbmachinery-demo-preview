## Explorer line icons — 2026-10-28

The `mx-*.svg` icons are simple original line drawings authored for this demo, using the existing 24×24, round-cap visual conventions. They represent cube, layers, operator panel, ring, process route, reset, zoom, isolate, expand, parent navigation and photo controls. They do not add a package dependency or reuse a brand mark. The Explorer header uses the existing official `assets/logo.webp` graphic.

- `pencil.svg`: Lucide, https://github.com/lucide-icons/lucide/blob/main/icons/pencil.svg; same ISC license as the existing Lucide icon set.
