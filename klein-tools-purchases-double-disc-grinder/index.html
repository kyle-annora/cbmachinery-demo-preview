Klein Tools Purchases Double Disc Grinder

Klein Tools selected a C&B double-disc cell for a new Texas plant manufacturing pliers. The rotary-carrier tooling was designed to accept multiple plier configurations and grind both faces together.

The announced production target was one finished part every three seconds. Flexible tooling supported the customer’s wider plier family. This is the performance target reported for the 2012 project.
