Centerless grinder rebuilds

C&B Machinery has extensive experience in rebuilding, remanufacturing, and controls upgrades on centerless grinders. We specialize in the following common scope of work:

Rebuild scope

  • Teardown, Inspection, and Cleaning of the Entire Machine
  • Hand Scraping of All Machine Precision Ways and Slides
  • Install New Lubrication System and/or Oil Mist System
  • Complete Reassembly of the Machine with Final Inspection
  • Automation Integration
  • Gauge Integration

Rebuild All Spindles

  • Grinding Wheel Spindle
  • Regulating Wheel Spindle
  • Dresser Spindle
