Blanchard grinder rebuilds

C & B specializes in customizing Blanchard style grinder for use in high volume production applications. C & B has re-engineered the Blanchard feed systems to incorporate the latest technologies such as servo-driven ball- screw feeds while eliminating a majority of moving components and the maintenance-related downtime that results.

CB1V-18-B (Blanchard 18A)

C & B this reworked machine to grind connecting rods. This machine type was ideal for that project because these machines offer tight tolerance control by having one side of the part fixed to the rigid work table. Stepped or equal side rods can be ground on this machine just by simply swapping out the tooling fixtures on the table.
