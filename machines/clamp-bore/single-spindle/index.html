Single Spindle Clamp Bore

Specifications:

  • Cast machine base
  • Vertical spindle axis orientation
  • Cup or ring disc grinding wheel
  • Variable rotations per minute
  • Servo drive feed system
  • In-process gauging
  • Feed rates: 1 - 30,000 mm/min
  • Position accuracy: .001 mm
  • AC motor with VF drive for rotation
  • Pneumatic clamping
  • 100 mm maximum workpiece diameter
  • 80 mm maximum workpiece length

Innovative Tooling Options

A single vertical spindle grinding machine has an extremely small footprint. Although perfect for one-sided grinds, the machine can be custom built to grind 2 sides of a part if needed.
