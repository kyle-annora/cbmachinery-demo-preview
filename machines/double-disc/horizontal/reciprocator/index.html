Reciprocator "Gun-Feed" Tooling

Integrated grinding cell corrects part orientation, checks via camera system for correct part number, robot loads 2 non-coplanar parts into the grinding machine, ground to size in one cycle, robot unloaded and gauged. Fully automated turn-key cell!

Specifications

  • Cast machine base
  • Horizontal spindle orientation
  • 30, 36 & 42-inch diameter grinding wheels
  • 3.75-inch grinding wheel width
  • 3900-6500 surface feet per minute
  • Spindle motor horse-power varies based on wheel size (20-100 HP)
  • Quill feed spindle type
  • Precision ball screw wheel feed
  • (.004-7.3) inches per minute feedrate
  • Servo driven reciprocator mechanism
  • Automatic dress cycle
